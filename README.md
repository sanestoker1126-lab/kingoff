# ST — Estoker Locations Money Services

Static HTML directory prototype. Open `index.html` in a browser or enable GitHub Pages from Settings → Pages → Deploy from a branch → main → /(root).

Features: CSV-backed searchable directory, Leaflet/OpenStreetMap display for records with valid coordinates, business details and source links, call logging saved in local browser storage, CSV import/export.

Important: This is a static prototype. Call notes and statuses are stored only in the current browser; they are not shared across users. Imported records and OSM candidates are not independently verified. No real business owner status should be inferred from directory listings.
